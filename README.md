## Introduction

Meteor Detection is a project designed to identify and track meteors in the night sky. By leveraging cutting-edge technology, we aim to provide accurate and real-time meteor detection.

## Features

- Real-time meteor detection
- High accuracy and precision
- Easy to use interface
- Scalable and efficient

## Installation

To install the Meteor Detection project, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/MeteorDetection.git
    ```
2. Navigate to the project directory:
    ```bash
    cd MeteorDetection
    ```
3. Install the required dependencies:
    ```bash
    ```bash
    poetry install
    ```
    ```

## Usage

To use the Meteor Detection project, run the following command:
```bash
python detect_meteors.py
```
