📤 上传图片

方式一：Web 上传

📁 点击或拖拽图片到此处

支持 JPG、PNG 格式

方式二：API 调用

# 单张检测
curl -X POST http://localhost:8000/api/tasks/ \
  -H "Content-Type: application/json" \
  -d '{"task_type":"single","params":{"image_path":"/path/to/image.jpg","background_path":"/path/to/bg.jpg"}}'

# 批量检测
curl -X POST http://localhost:8000/api/tasks/ \
  -H "Content-Type: application/json" \
  -d '{"task_type":"batch","params":{"image_dir":"/path/to/images"}}'
